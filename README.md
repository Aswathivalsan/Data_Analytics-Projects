# String-Tuples
Python Assignment 1: Data Structures – Strings & Tuples

1. Introduction

This assignment focuses on Python data structures, particularly strings and tuples. It covers string concatenation, indexing, slicing, string methods, tuple creation, concatenation, repetition, and element access.

2. Objectives

To understand string concatenation using the + operator.

To perform string indexing and slicing.

To apply built-in string methods.

To create and combine tuples.

To access and repeat tuple elements using indexing and slicing.

3. Implementation

String Concatenation: Two strings are combined using the + operator. The input() function accepts the user's name, and the final greeting is displayed using print().

String Slicing and Indexing: Indexing is used to access individual characters, while slicing extracts specific portions of a string. Reverse slicing is used to display the string in reverse order.

String Methods: The methods upper(), lower(), capitalize(), count(), and replace() are used to modify text presentation, count character occurrences, and replace specified words.

Tuple Operations: Two tuples containing (10, 20, 30) and (40, 50, 60) are created. They are concatenated using +, repeated using *, and accessed using indexing and slicing.

4. Results

The programs successfully demonstrate string manipulation and tuple operations. The output displays the concatenated greeting, selected characters, sliced and reversed strings, transformed text, and combined and repeated tuples.

5. Conclusion

This assignment provides practical knowledge of Python strings and tuples. It helps develop an understanding of basic Python operators, built-in methods, indexing, and slicing, which are essential for programming and data manipulation.

**Python Assignment 2 – Data Structures and Conditional Statements**
